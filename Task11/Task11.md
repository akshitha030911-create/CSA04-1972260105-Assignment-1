# TASK 11 – Final Operating-System Plan

## Proposed Design

1. Bedside Patient Monitors:
Hard Real-Time Operating System.
Provides deterministic scheduling, sensor handling and fast alarm processing.

2. Nurses' Tablets:
Mobile Operating System.
Provides battery management, wireless communication and secure access.

3. Doctors' Workstations:
Desktop Operating System.
Provides multitasking, user interfaces and medical application support.

4. Patient Database:
Clustered Server Operating System.
Provides backup, replication, data security and failover.

5. MRI Imaging Server:
Symmetric Multiprocessing Operating System.
Provides parallel processing and high-speed data transfer.

6. Partner Hospital Network:
Distributed System.
Provides secure communication and information sharing between hospitals.

## Security Measures

- Authentication.
- Encryption.
- Role-based access control.
- Regular security updates.
- Data backups.
- Audit logging.
- Disaster recovery.

## Advantages

- Better patient safety.
- High system reliability.
- Improved processing speed.
- Secure medical records.
- Efficient resource management.

## Challenges

- Higher implementation cost.
- Complex administration.
- Network failures.
- Compatibility issues.

## Conclusion
A combination of specialized operating systems provides better performance, security and reliability for a smart hospital than a single operating system.

# TASK 04 – Operating-System Services

## Essential Services

1. Patient Monitors:
- Sensor input and output.
- Real-time scheduling.
- Alarm processing.
- Error detection.
- Memory protection.

2. Nurses' Tablets:
- Touchscreen interface.
- Wireless communication.
- File management.
- Power management.
- Authentication.

3. Doctors' Workstations:
- User interface.
- Program execution.
- File management.
- Networking.
- Security updates.

4. Patient Database:
- File management.
- Process management.
- Access control.
- Data protection.
- Backup and recovery.

5. MRI Server:
- Memory management.
- Parallel processing.
- High-speed input/output.
- Storage management.
- Networking.

## Security Requirements

The patient database must provide:
- Authentication.
- Authorization.
- Role-based access control.
- Encryption.
- Audit logs.
- Backup and recovery.

## Alternative Design

Using a full desktop operating system on every tablet would increase memory usage, background activities and battery consumption.

A mobile operating system is better because it provides power management and only the required services.

## Conclusion
Selecting the correct operating-system services improves security, reliability and performance in a smart hospital.
